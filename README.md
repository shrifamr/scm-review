# موقع مراجعة SCM

موقع مراجعة static لمادة Supply Chain Management، يدمج الشرح وبنك الأسئلة المرفوعين. لا يحتاج إلى خادم خلفي أو تثبيت حزم أو اتصال بخدمة خارجية.

## الملفات

- `index.html`: الصفحات والتنقل والمحتوى الأصلي للشرح.
- `styles.css`: تنسيق متجاوب للهاتف والحاسوب، مع دعم الوضع الليلي.
- `app.js`: البحث، المذاكرة، الاختبارات، المؤقت، التصحيح، والحفظ المحلي.
- `data.js`: بيانات الأسئلة المستخرجة من الملفين المرفوعين.
- `favicon.svg`: أيقونة الموقع.

## عدد الأسئلة وملاحظة المصدر

عنوان ملف البنك يقول 100 سؤال. فحص البيانات الفعلية في `index.html` المرفوع وجد 100 سؤال كامل البنية: 50 + 25 + 25. هذا لا يطابق ملاحظة الطلب التي ذكرت 98 (50 + 25 + 23). احتفظ الموقع بكل الأسئلة الموجودة في المصدر ولم يحذف أو يخترع سؤالين. كذلك يحتوي ملف الشرح البصري على اختبار قصير منفصل من 12 سؤالًا، أُبقي كمجموعة مستقلة.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا، أو افتح المستودع الذي تريد النشر منه.
2. انسخ ملفات الموقع الخمسة (`index.html` و`styles.css` و`app.js` و`data.js` و`favicon.svg`) إلى جذر المستودع. يمكن إبقاء `README.md` معه.
3. ارفع التغييرات إلى الفرع الذي ستنشره.
4. من إعدادات المستودع افتح **Pages**، ثم اختر النشر من الفرع ومجلد الجذر `/`، واحفظ الإعداد.
5. افتح رابط GitHub Pages الذي يظهر في إعدادات Pages. قد يحتاج أول نشر إلى وقت قصير حتى يظهر.

إذا كان النشر من مجلد `docs`، انسخ ملفات الموقع الخمسة إلى `docs` واختر ذلك المجلد كمصدر النشر. الروابط بين الملفات نسبية، لذلك يعمل الموقع أيضًا تحت مسار مشروع GitHub Pages.

## التشغيل المحلي

يمكن فتح `index.html` مباشرة في متصفح حديث. ولتجربة أقرب إلى GitHub Pages، شغّل خادم ملفات ثابت داخل هذا المجلد ثم افتح عنوانه المحلي. لا توجد عملية بناء.

## استخدام الموقع

- **الشرح:** تنقل بين المحاضرات 1 و2 و3 و6.
- **مذاكرة:** إجابة سؤال بسؤال مع تصحيح فوري ورابط إلى المحاضرة ذات الصلة.
- **اختبار:** اختر مجموعة الأسئلة، وفعّل أو أوقف خلط الأسئلة والاختيارات، وحدد مؤقتًا اختياريًا.
- **بنك الأسئلة:** ابحث في الأسئلة والاختيارات وصفِّ النتائج حسب المجموعة وحالة الإجابة.
- **التقدم:** تُحفظ الإجابات على المتصفح الحالي. استخدم التصدير والاستيراد لنقلها إلى متصفح آخر أو جهاز آخر.
- **الوضع الليلي:** يتبدل من زر أعلى الصفحة ويُحفظ اختياره محليًا.

التصحيح يعرض الإجابة الواردة في البنك، ويربطها بالمحاضرة المقابلة عند توفر مرجع في الشرح. لم تُضف تفسيرات دراسية من خارج الملفين.
